# Student Management System (Java)

## Description
A console-based Java application to manage student records with support for semester-wise results and subject-wise marks tracking. The system allows efficient handling of academic data using object-oriented design principles.

## Features
- Add, update, and delete student records
- Search student by ID
- Manage semester-wise results
- Add subject-wise marks for each semester
- Input validation and error handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections (ArrayList)

## Project Structure
- `Student` class for storing student details
- `SemesterResult` class for managing semester data
- `SubjectMark` class for subject-wise marks
- Main system class for handling operations

## How to Run

### Compile
javac StudentManagementSystem.java

### Run
java StudentManagementSystem
